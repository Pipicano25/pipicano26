# pipicano26

Sitio web estático sobre la región del Sur Occidente colombiano (Valle del Cauca, Cauca y Nariño). Presenta una página principal y una página por departamento, usando Bootstrap. Es un ejercicio de la asignatura "Lenguajes de última generación".

## Tecnologías

- HTML
- CSS
- Bootstrap

## Uso

Abrir `index.html` en un navegador y navegar entre las páginas de Valle, Cauca y Nariño.

## Estructura

- `index.html` — página principal del Sur Occidente colombiano.
- `valle.html`, `cauca.html`, `Nariño.html` — páginas de cada departamento.
- `css/` — Bootstrap y estilos.
- `img/` — imágenes de cada departamento.
- `DOX/` — documento parcial (Word y PDF).
